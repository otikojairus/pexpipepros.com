# Pex Pipe Pros

Programmatic SEO Next.js site for `pexpipepros.com`.

## Data source

- Spreadsheet input: `Poly B to Pex pSEO - pexpipepros.com .xlsx`
- Generated page dataset: `lib/pex-data.ts` (162 pages)

## Commands

- `npm run dev` - local development
- `npm run lint` - lint checks
- `npm run build` - production build
- `npm run start` - run production server
